此 Profile 用於交換脆家案件的主責社工或其他服務提供者資料；案件中的 `EpisodeOfCare.careManager` 與撤尋紀錄的 `Provenance.agent.who` 均參照此 Profile。

此 Profile 繼承 TWSS Base Practitioner Profile，並使用自然人憑證卡號識別主責社工。

#### 可能可以支援以下查詢參數：

可參閱 [FHIR R4 Practitioner 原生查詢參數](https://hl7.org/fhir/R4/practitioner.html#search)。
